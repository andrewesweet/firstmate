  subreaper (pid 562, `systemd --user`), never to pid 1. Probe:
    ( sleep 3 & echo $! > /tmp/orph.pid ); ps -o ppid= -p $(cat /tmp/orph.pid)  => 562
- Reproduced on a clean upstream/main clone (kunchenguid/firstmate 1b1b6e0):
